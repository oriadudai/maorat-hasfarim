# 🐉 מאורת הספרים

מעקב אחרי ספרים והשאלות.

- `server/` – קוד Google Apps Script (מודבק בעורך של ה-Sheet): `Code.gs`, `Index.html`
- `docs/` – האתר הציבורי (GitHub Pages), קריאה בלבד
- `android/` – אפליקציית אנדרואיד שעוטפת את `server/Index.html` ומוסיפה סריקה חיה ומטמון אופליין

APK אחרון: https://github.com/oriadudai/maorat-hasfarim/releases/latest/download/maorat-hasfarim.apk
